# API-тесты Miro

В проекте находятся три теста для Sticky Note: создание и получение,
изменение, удаление.

## 1. Установка зависимостей

В терминале PyCharm выполнить:

```bash
pip install -r requirements.txt
```

Для открытия графического Allure-отчёта также потребуется установленная
утилита Allure Commandline. Для самого запуска тестов достаточно Python-пакетов.

## 2. Переменные окружения

В конфигурации запуска PyCharm добавить:

```text
MIRO_ACCESS_TOKEN=ваш_токен
MIRO_BOARD_ID=id_тестовой_доски
```

Токен не следует вставлять в исходный код или отправлять в Git.

## 3. Запуск

```bash
pytest
```

Результаты для Allure будут записаны в каталог `allure-results`.

Чтобы сформировать и сразу открыть отчёт:

```bash
allure serve allure-results
```

## Как выполняется один тест

1. Pytest получает токен и ID доски через фикстуры.
2. `sticky_note_factory` создаёт тестовый объект и запоминает его ID.
3. Тест выполняет запросы и проверки `assert`.
4. После теста фабрика удаляет созданный объект.

Если проверка внутри теста завершится ошибкой, код после `yield` в фикстуре
всё равно будет вызван, поэтому тестовые Sticky Note не должны накапливаться
на доске.
