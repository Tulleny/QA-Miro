# QA Miro

Дипломный проект по функциональному тестированию инструментов интерактивной доски Miro.

## Область тестирования

Sticky Notes, Text, Shapes, Connectors и Frames. Проверяются создание и редактирование объектов, оформление, выделение, перемещение, изменение размера, копирование, удаление, группировка, Undo и Redo.

Ручное тестирование выполняется в Google Chrome и Яндекс Браузере на Windows 10. Kanban и списки исключены из области тестирования согласно тест-плану.

## Автоматизация

Python, pytest, requests и Allure. Три API-теста проверяют:

1. Создание и получение Sticky Note.
2. Изменение текста, цвета и положения Sticky Note с проверкой через GET.
3. Удаление Sticky Note и проверку отсутствия объекта.

Фикстуры подготавливают HTTP-сессию и удаляют созданные тестовые объекты после выполнения тестов.

## Размещение файлов

После загрузки проекта его структура должна выглядеть так:

```text
conftest.py
pytest.ini
requirements.txt
tests/
    test_sticky_notes.py
allure-results/
```

Файлы Python, конфигурация и результаты Allure загружаются отдельно. Архив проекта нужно распаковать перед загрузкой.

## Запуск

Из корня проекта установить зависимости:

```bash
python -m pip install -r requirements.txt
```

В окружении процесса запуска задать `MIRO_ACCESS_TOKEN` и `MIRO_BOARD_ID`. Токен должен иметь права `boards:read` и `boards:write`, а доска — быть доступной приложению.

При запуске через PyCharm переменные задаются в конфигурации запуска. При запуске через терминал их нужно задать в этом терминале.

```bash
python -m pytest --alluredir=allure-results
```

Для просмотра результатов установить Allure Commandline и выполнить:

```bash
allure serve allure-results
```

Python-пакет `allure-pytest` сохраняет результаты; команда `allure` устанавливается отдельно.

## Результаты

По выполненному прогону: 12 ручных тест-кейсов пройдены в каждом из двух браузеров. Три API-теста пройдены; время запуска pytest — 3,98 с. В рамках выполненных проверок дефектов не обнаружено.

## Публикация

Не загружать токены, файлы `.env`, виртуальное окружение и локальные настройки IDE. Каталог `allure-results` разрешён для добавления в репозиторий. Перед публикацией вложений отчёта проверить, что они не содержат секретов или личных данных.
